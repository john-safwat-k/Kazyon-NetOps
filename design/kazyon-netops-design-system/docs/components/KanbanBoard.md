# KanbanBoard

Page 3, the Jira-style board (`/tickets/board`) with the eight lifecycle columns from the BRD: Awaiting Regional IT, New & Diagnosing, Branch / Internal Action, Escalated to ISP (2h), With ISP (4–6h), Verifying Fix, Needs Human Review, Resolved / Closed.

- Filter row above the board (ISP, region, trigger, priority, AI paused).
- ISP columns are marked in brand orange, Needs Human Review in critical, Resolved in good.
