# KpiCard

A headline number for the Executive & SLA Dashboard KPI row.

- `label`, `value`, `icon`, `hint` (one muted line).
- `delta`: `"+6"` or `"-3"`. For incident counts up is bad, so `+` renders in critical and `-` in good.
- `tone`: `default | warning | critical`. Use critical only for items that need a person now (Needs Human Review).
